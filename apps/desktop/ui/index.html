Créer votre coffre

Le coffre est chiffré sur ce poste par une suite hybride, classique et post-quantique. Choisissez un mot de passe maître : lui seul l'ouvre, et il ne peut pas être récupéré.

Au moins 12 caractères. Une phrase de plusieurs mots est plus facile à retenir et plus difficile à deviner.

La création calibre le chiffrement sur ce poste : comptez quelques secondes.

      Import KeePass (KDBX)

      L'import direct d'une base KeePass n'est pas encore disponible : il demande une bibliothèque de déchiffrement que nous n'avons pas encore validée.

      En attendant, exportez votre base au format CSV, importez le fichier, puis supprimez-le :

      • KeePassXC : Base de données › Exporter › Fichier CSV ;
      • KeePass 2 : Fichier › Exporter › KeePass CSV (1.x).

      Un fichier CSV contient vos mots de passe en clair : gardez-le le moins longtemps possible.
