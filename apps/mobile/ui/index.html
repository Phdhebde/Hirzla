HIRZLA

Créer votre coffre

Le coffre est chiffré sur ce téléphone par une suite hybride, classique et post-quantique. Choisissez un mot de passe maître : lui seul l'ouvre, il ne peut pas être récupéré.

Rejoindre mon compte

Ce téléphone devient un appareil de votre compte : il reçoit vos casiers partagés. Collez le lien d'invitation du serveur (il commence par « hirzla-invitation: »).

Code de ce téléphone

Sur votre poste, ouvrez Serveur › Ajouter un appareil (ou « hirzla appareil ajouter ») et saisissez ce code. Il expire dans 10 minutes. Gardez ce téléphone allumé, Hirzla à l'écran, jusqu'à la fin.

En attente du poste…

Comparez l'empreinte

Le poste affiche l'empreinte de votre clé de membre. Elle doit être identique, caractère par caractère. Sinon, n'allez pas plus loin : quelqu'un s'interpose.

Mot de passe de ce téléphone

Il ouvre le coffre de ce téléphone seulement. Il peut différer de celui du poste ; il ne peut pas être récupéré.

        Empreinte

        L'empreinte ouvre le coffre grâce à une clé gardée dans la puce sécurisée du téléphone (StrongBox). Le mot de passe maître reste nécessaire pour l'ajouter, et ouvre toujours le coffre.

        Saisie automatique

        Dans un formulaire de connexion, Android propose « Remplir avec Hirzla ». Hirzla s'ouvre, vous choisissez le secret, et vous revenez au formulaire rempli. Dans Chrome, activez aussi « Saisie automatique à l'aide d'un autre service » dans les réglages du navigateur.
